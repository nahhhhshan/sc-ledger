# StarCitizen LEDGER

A ledger for Star Citizen: track your aUEC income and expenses by contract type, see your balance history, and unlock achievements. Import records straight from `Game.log`. Japanese / English.

Star Citizen の収支帳です。契約の種類ごとの収入・支出、所持金の推移、実績を記録できます。`Game.log` から取り込めます。日本語 / English。

**https://nahhhhshan.github.io/sc-ledger/**

- Records are stored only in your browser. Nothing is sent anywhere. Save a backup from "Balance settings" now and then.
- 記録はブラウザ内にだけ保存され、どこにも送信されません。「所持金の設定」からときどきバックアップを保存してください。
